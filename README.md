# creator1x · ТГКсборщик

Навык для Codex и Claude Code: собрать Telegram-бота вместе с оформлением, управлением, доступом и запуском.

## Что делает

- Собирает функции бота по задаче и доводит их до проверяемого результата.
- Готовит приветствие, справку, эмодзи, меню команд и настоящие кнопки, включая нативные цветные стили Telegram.
- Подготавливает аватар и картинку/GIF для блока «Что умеет этот бот?» в BotFather; учитывает доступность генератора изображений в конкретной среде.
- Добавляет проверку подписок на выбранные каналы и защищает обработку и старые кнопки от обхода проверки.
- Для медиа-ботов учитывает форматы, ограничения, удаление фона, эффекты, эмодзи и стикеры.
- Помогает выбрать хостинг, подготовить размещение, перезапуск, хранение данных и проверки. Предусмотрены Telegram Serverless и VPS, например Hetzner.

Это инструкции для AI-агента, а не готовый универсальный бот или хостинг. Токен, права каналов, доступ к серверу и инструменты генерации изображений предоставляются в конкретном проекте. Навык не покупает сервер и не подключает платные API без авторизации.

## Установка

Скачайте этот репозиторий и поместите его содержимое в папку навыка:

- Codex: `~/.codex/skills/tgk-sborshchik/`
- Claude Code: `~/.claude/skills/tgk-sborshchik/` или `.claude/skills/tgk-sborshchik/` внутри проекта.

В корне папки должен лежать `SKILL.md`. Откройте новую сессию после установки. Для облачных сессий Claude Code локальная личная папка недостаточна — используйте поддерживаемую проектную установку.

## Важные различия

Проверка подписок может быть написана, но не подключена: нужны реальные ID каналов и права администратора для бота. Бесплатный доступ к боту не означает бесплатный хостинг. Telegram Serverless предусмотрен как отдельный маршрут; актуальные тарифы и квоты проверяются перед размещением. Python/FFmpeg/модели требуют подходящей среды, обычно VPS или отдельного worker.

## Проверка картинки для BotFather

Для локальной проверки размеров и кодека нужен Python 3 и `ffprobe` из FFmpeg:

```sh
python3 scripts/check_description_media.py /path/to/description.gif
```

Проверка не отправляет файл и не заменяет подтверждение BotFather. Подробные инструкции находятся в `SKILL.md` и `references/`.
