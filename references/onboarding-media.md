# Оформление и Description Picture

[BotFather](https://core.telegram.org/bots/features#botfather) управляет pre-start блоком «What can this bot do?» через Edit Description Picture. /start фото не заменяет этот блок. Имя, description, about, commands настраиваются методами актуального Bot API, profile photo — при поддержке API/SDK. Установку Description Picture проверять отдельно; не обещать неизвестный метод Bot API.

Размеры подтверждены сообщением BotFather в реальной настройке Emojinator 2026-10-09: фото 640×360; GIF 320×180, 640×360 или 960×540. Повторно сверить текущую подсказку BotFather. Подготовить финальный PNG/JPEG640×360 отдельно от большого исходника; осмотреть кроп, сохранить полный силуэт. В качестве GIF делать мягкий цикл с паузой, первый/последний кадр без скачка; статичную альтернативу сохранить.

Telegram [хранит GIF как H264/MPEG4 без звука](https://core.telegram.org/api/gifs). Если BotFather отвечает «Please send a photo or a GIF», это может быть неправильный тип сообщения Document/Video, а не ошибка размеров. Не заявлять причину без фактического payload. Проверить исходный файл; затем выдавать владельцу через sendAnimation/reply_animation H264 MP4 без аудио и с нужными dimensions, чтобы он переслал Animation в BotFather. В Emojinator этот способ пользователь подтвердил как успешный. Нельзя считать отображаемую длительность на скриншоте доказательством другого файла.

Не советовать бесконечно переотправлять «как файл» после отказа. При dimensions invalid проверить локальный экспорт и фактические width/height сообщения, не исходный prompt. `scripts/check_description_media.py` проверяет локальные метаданные. Успех установки — ответ BotFather и просмотр pre-start блока, не только генерация файла.

Для иллюстрации генератору дать назначение, согласованный персонаж/палитру, композицию, ограничения текста и поля. Без доступного генератора не имитировать его результат или идентичность другой модели. Готовые активы переносить в проект; внешнее временное расположение не является поставкой.
