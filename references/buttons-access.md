# Кнопки и подписки

Проверено 2026-10-09 по [Bot API](https://core.telegram.org/bots/api#keyboardbutton): KeyboardButton и InlineKeyboardButton поддерживают `style`: `primary` — синий, `success` — зелёный, `danger` — красный. Произвольный цвет не задаётся. Обычным цветным кнопкам не нужен сторонний бот или Premium; custom emoji icons имеют отдельные ограничения. Проверить SDK и клиент, не менять SDK молча ради внешнего вида. В python-telegram-bot 22.8 параметр style доступен в обоих типах.

Цвет — смысл действия: основное положительное success, информационное primary, удаление danger. Не красить всё подряд. На узком экране длинные названия вынести в отдельную строку; native resize/persistent — по сценарию.

Reply-кнопка отправляет текст: маршрутизировать точное имя через таблицу в тот же обработчик команды. Inline callback — проверить owner, перечисленные действия/ID и текущее право доступа; ответить на callback без ожидания долгого рендера. Командное меню и клавиатура — разные элементы. Служебное /banner можно скрыть для обычных пользователей.

## Gate

Использовать [getChatMember](https://core.telegram.org/bots/api#getchatmember); гарантированная проверка других пользователей требует администратора бота в канале. Invite-ссылка не равна chat_id. Для закрытого канала получить реальный числовой ID; не выводить его из invite hash. Служебный /channelid только владельцу; пересылка с защищённого канала может быть недоступна.

Startup: каналы существуют, разные, бот администратор; ошибка конфигурации не открывает публичный доступ. Для проверки членства разрешать member/administrator/creator и restricted только при is_member=true; left/kicked и ошибки API закрывают защищённую обработку. Проверка охватывает upload, render, export, pack и старые кнопки, а не только /start. Короткий cache допустим с явно выбранным сроком; не обещать мгновенную отписку при длинном cache.

Пользователь видит ссылки и «Проверить подписку», ошибки API отличаются от отсутствия подписки. Setup-mode только для allowlisted владельцев. Тестировать отсутствие одной из подписок, ошибки и отписку. До реальной конфигурации писать «проверка реализована, но отключена», не «работает».
