# Если назначение — фото → эмодзи/стикеры

Не включать этот набор функций в чужой бот автоматически. Если выбран именно этот сценарий: принять фото и документы согласованных форматов, сохранить прозрачность, предоставить удаление фона, экспорт без эффекта, затем выбранные эффекты (например блик/флаг/пульс/покачивание). Ограничения входа выбирать по нагрузке, объяснять пользователю байты, пиксели, расширения и почему GIF/видео не подходят статичному входу.

Актуальные ограничения проверять в [Telegram Stickers](https://core.telegram.org/stickers). Реальные размеры статичного custom emoji 100×100 и sticker с одной стороной 512; PNG/WEBP по требованиям API. Video sticker/emoji — WEBM VP9 с правильным размером, alpha где нужна, без звука; длительность, FPS и размер файла сверить перед реализацией. Не считать GIF подходящим форматом стикера только потому, что он принят Description Picture. Проверить реальную альфу после декодирования, полный силуэт и цикл; name pack, ownership и create/add идемпотентность.

Объяснить актуальные [условия custom emoji](https://core.telegram.org/stickers#custom-emoji), включая Premium для использования собственных наборов. Не смешивать бесплатную обработку с доступностью функции в клиенте.

Проверять magic/декодирование, decompression bombs, frame count, pixel count, max bytes до модели. Пользовательские filename и callback не должны становиться путём или shell-командой. Тяжёлый рендер ограничить по concurrency и admission, cleanup не удаляет активную работу, глобальный диск ограничить отдельно от per-user лимита. Не передавать фотографии внешнему AI-сервису без авторизации. /delete объясняет, какие временные данные удалены и какие опубликованные сообщения/наборы остаются в Telegram.
